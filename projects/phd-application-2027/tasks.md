- [ ] 篩查學校（10–15 校 + advisor list）
- [ ] 寄信給 3–5 個 advisor（自我介紹 + 履歷）
- [ ] SOP 一稿（1500 字）
- [ ] SOP 二稿 / 潤稿 / 教授 check
- [ ] CV 學術版（含 publication）
- [ ] 請 3 位教授 / 主管寫推薦信（11 月前提出）
- [ ] 報考 TOEFL / GRE（如需要）
- [ ] 申請各校帳號、填資料
- [ ] SOP / 文件 final 校稿（依 due 排程）
- [ ] 投出（依 due：12/1 → 12/15 → 1/15）
