## 文件 Checklist

- [ ] SOP 主稿（1500 字）
- [ ] Personal Statement / Diversity Statement（部分校要）
- [ ] CV（學術版，含 publication list）
- [ ] 3 封推薦信（教授 + 業界主管）
- [ ] Transcript（中英）
- [ ] TOEFL ≥ 100 / IELTS ≥ 7
- [ ] GRE（部分校要，看官網）
- [ ] Writing sample（部分校要）
- [ ] 申請費（USD 75–120 / 校）
