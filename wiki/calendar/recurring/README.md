# Recurring Habits — Algorithms

Reference for AGENTS.md § 5 Recurring habits. One habit file per topic.

## Schema

```yaml
---
type: recurring
title: <short noun phrase>
frequency: <daily | every-N-days | weekdays | Mon,Wed,Fri>
check-state: <daily-note-checkbox | last-date-field>
reminder: <morning-first-turn | evening-review | daily-ondue>
tags: [optional]
---
```

| Field | Required | Notes |
|---|---|---|
| `type:` | ✅ | always `recurring` |
| `title:` | ✅ | short noun phrase |
| `frequency:` | ✅ | see § Frequency values |
| `check-state:` | ✅ | see § Check-state methods |
| `reminder:` | ✅ | see § Reminder policies |

## Frequency values

| Value | Example | Math |
|---|---|---|
| `daily` | supplements 2x/day | fires every day |
| `every-N-days` | `every-2-days` (gym) | days_since >= N since `last_date` |
| `weekdays` | daily standup | Mon-Fri only |
| `Mon,Wed,Fri` | weight training | explicit day list |

## Check-state methods

| Method | Storage | When to update |
|---|---|---|
| `daily-note-checkbox` | `wiki/daily/YYYY-MM-DD.md` per-day `[ ]` | User confirms in conversation |
| `last-date-field` | habit file frontmatter `last_date: YYYY-MM-DD` | User confirms; agent updates field |

## Reminder policies

| Policy | When |
|---|---|
| `morning-first-turn` | first user turn of the day |
| `evening-review` | end of day review (user says "done for today", or agent sees time >= 21:00) |
| `daily-ondue` | fires whenever SOP-Daily-Brief detects habit is due |

---

## Algorithms

### A. Daily habit with daily-note checkbox

Example: supplements 2x/day.

**State**: daily-note `## ☐ → ☑ Supplements` section with Morning / Evening subsections.

**Agent loop** (each user turn):

1. Open today's daily note.
2. If `## 💊 Supplements` section missing → generate it (per § C template below).
3. Read Morning row: `[ ]` unchecked or `[x]` checked.
5. **Morning trigger** — first user turn of day:
   - If Morning row unchecked → prompt "早上保健品吃了嗎？"
6. **Evening trigger** — when user says "done for today" OR agent sees time >= 21:00 AND other content in daily note:
   - If Evening row unchecked → prompt "晚上保健品吃了嗎？"
7. User reply "吃了 / done / yes" → agent toggles `- [x]` in the right subsection, appends the actual supplement name if user provides.

### B. Every-N-days habit

Example: gym every 2 days.

**State**: habit file frontmatter `last_date: YYYY-MM-DD`.

**Agent loop** (SOP-Daily-Brief each morning):

1. Read `last_date:` from habit file. If absent → treat as "due today" (first-time tracking).
2. Compute `days_since = today - last_date`.
3. If `days_since >= N` → write `## 🏋️ Gym due today` section in today's daily note (idempotent: don't duplicate).
5. If `days_since < N` → omit entirely (no mention).
6. After user confirms "去了 / done" → agent updates habit file's `last_date:` to today.

### C. Daily note `## Recurring` template

Agent generates this section on file creation by reading all habit files in `wiki/calendar/recurring/`:

```markdown
## Recurring

<!-- auto-generated by SOP-Recurring § A/B -->

### 💊 Supplements

#### Morning
- [ ]

#### Evening
- [ ]

<!-- (gym, exercise, etc. — auto-appended when their rules fire) -->
```

Habit sections are appended only when their § A or § B fires. Paused habits (`status: paused`) are skipped.

## Examples

### `wiki/calendar/recurring/habits.md`

```yaml
---
type: recurring
title: Supplements
frequency: daily
check-state: daily-note-checkbox
reminder: morning-first-turn, evening-review
last_morning:
last_evening:
tags: [health, daily]
status: active
---
```

```markdown
# Supplements

Daily, twice-daily.

## Morning
User takes multivitamin, omega-3, vitamin C.

## Evening
User takes magnesium, calcium.

[agent reads daily note for actual content; supplements vary.]
```

# Gym

Every 2 days.

[last_date updated by agent after user confirms.]
